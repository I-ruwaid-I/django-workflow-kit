# Examples

Run the examples to see Django Workflow Kit in action.

## Invoice Approval

Planned with Phase 1. `examples/invoice_approval` will demonstrate:

```text
Draft
 ↓
Manager Review
 ↓
Finance Review
 ↓
Approved
 ↓
Paid
```

- Permissions
- Approval and rejection
- Comments, timeline and audit history
- Conditional routing based on invoice amount

Same simple application, no workflow required beyond what Django Workflow Kit
provides.
